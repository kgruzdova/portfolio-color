# Ксения Груздова — Color

Самостоятельный лендинг-портфолио: серо-зелёная палитра, заголовки Garamond, шрифт Inter и реальные кейсы.

Сайт: https://kgruzdova.github.io/portfolio-color/

## Запуск

Откройте `index.html` в браузере. Сборка и установка пакетов не требуются.

## Редактирование

- `index.html` — разделы и основной текст.
- `content.js` — кейсы, будущие работы и контакты.
- `style.css` и `cases.css` — оформление и анимация.
- `assets/` — изображения.

GitHub Pages публикует корень ветки `main`. После отправки изменений дождитесь завершения Pages build and deployment во вкладке Actions.

Контакты и обработчик формы пока не заполнены. До подключения `formEndpoint` форма не отправляет сообщения, но позволяет скачать заявку. Не добавляйте секретные API-ключи в клиентские файлы.

Версия Контраст находится в отдельном репозитории: https://github.com/kgruzdova/portfolio-contrast
